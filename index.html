Supporting cloud project

AWS VPC provisioning with Terraform & Jenkins

A public infrastructure example that defines an AWS network in version-controlled code and puts the Terraform workflow into a Jenkins pipeline.

TerraformAWS VPCJenkinsInfrastructure as code
View source ↗
OBJECTIVE

Make VPC configuration and provisioning steps explicit and repeatable instead of relying on manual console actions.

SOLUTION

Terraform defines an AWS VPC with configurable CIDR, DNS support, and DNS hostnames. Jenkins runs init, validate, plan, and apply on a Windows agent using stored AWS credentials.

DELIVERABLE

A reviewable VPC definition and four-stage provisioning pipeline, with region and network range exposed as configuration variables.

Explore implementation

Provisioning flow

  1. Jenkins Windows agent
  2. Terraform init / validate / plan / apply
  3. AWS provider
  4. VPC with DNS support

Public infrastructure example. Production usage, deployment success, and performance metrics are not documented in the repository.
